Training Piscine Python - Array exercises (ex00..ex05)

This workspace contains reference implementations for exercises 00 through 05.

Requirements:
- Python 3.10
- packages in requirements.txt

How to run a tester (PowerShell):
```powershell
python .\ex00\tester.py
python .\ex01\test_array2D.py
python .\ex02\tester.py
python .\ex03\zoom.py
python .\ex04\rotate.py
python .\ex05\tester.py
```

Notes:
- Each module follows the "no global code" rule and exposes the functions asked in the exercises.
- Image loaders will generate a small sample image if the requested file is missing so testers run out-of-the-box.
